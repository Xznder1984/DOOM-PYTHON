# Contributing

Just keep it simple and easy to read. Add maps, tweak guns, improve readability. Keep files split as they are.

1. Fork [github.com/Xznder1984/DOOM-PYTHON](https://github.com/Xznder1984/DOOM-PYTHON)
2. Make changes (keep style clean, comments helpful)
3. Test it runs: `python run.py`
4. Open a PR
