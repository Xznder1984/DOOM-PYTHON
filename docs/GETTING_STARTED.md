# Getting Started

## Install

You need Python 3.11+ and pygame.

```bash
pip install pygame-ce
```

## Run

```bash
python run.py
```

## First Time

1. Hit PLAY on the menu
2. Use WASD + Mouse to look around
3. Press TAB to pick different maps
4. Press 1-4 to switch guns, SPACE to shoot
5. Press M to change view (default is big view + small map)

## Tips

- If your mouse is locked, click the window or press ESC once to release it
- Ghosts are Pac-Man style and will chase you when close
- Maps must have `#` borders and exactly one `S` for start
- Everything is in separate files so it's easy to read
