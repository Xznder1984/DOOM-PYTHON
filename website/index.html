DOOM-PYTHON

A tiny, easy-to-hack Doom-style raycaster. Big view. Ghosts. Guns. Custom maps.

G = Ghost | R = Raycaster

Features

Classic Raycasting

First-person view with sky, floor, walls. Default is big raycasting + small map overlay.

Pac-Man Style Ghosts

Four colorful ghosts that chase you around the level.

4 Guns + Ammo

Pistol, Shotgun, Chaingun, Plasma Rifle. Cycle with 1-4 or Q/E, shoot with SPACE.

Easy Custom Maps

Draw ASCII maps in seconds. Add to maps/custom_maps.py and pick with TAB.

Split Into Files

Clean, readable code split across files so you can actually learn and mod it.

Mouse Look

Look around with your mouse, move with WASD. Feels great.

Quick Start

$ pip install pygame-ce
$ git clone https://github.com/Xznder1984/DOOM-PYTHON.git
$ cd DOOM-PYTHON
$ python run.py

Make Your Own Map

reg('my_map', 'My Map', [
    "##########",
    "#S........#",
    "#..####..#",
    "#........#",
    "##########",
])

Add this to maps/custom_maps.py and it'll show up in the TAB menu.
