DOOM IN PYTHON

A fully playable Doom-style raycaster built from scratch with Pygame. Easy to hack, mod, and extend.

terminal
$ pip install pygame-ce
$ git clone https://github.com/Xznder1984/DOOM-PYTHON.git
$ cd DOOM-PYTHON
$ python run.py

Create Your Own Maps

It's ridiculously easy

Maps are just ASCII grids. Add them to maps/custom_maps.py and they'll appear in the in-game map selector (press TAB).

  • # = Wall
  • . = Floor
  • S = Player Start
maps/custom_maps.py
from map_manager import register_map
# Add your maps here
register_map('arena', 'Death Arena', [
"##########",
"#S........#",
"#..####..#",
"#........#",
"##########",
])
